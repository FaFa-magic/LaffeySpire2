# 芯片方格比例修正（2026-09-27）

本页记录 2026-09-27 的修正结果。2026-09-28 已进一步取消逐格采样和空缺格 alpha 裁切，改为整图等比绘制以保留完整金属边框和倒角。当前规则与 17 张更新图片见 [边框与头像修订](rim-refresh.md)。下文尺寸和导出步骤保留为历史记录。

旧渲染先按 alpha ≥ 26/255 查找外接矩形，再分别用宽度/列数和高度/行数采样，最后把矩形区域铺到正方形格子。倒角、引脚和生成轮廓都会影响外接矩形，因此即使差异很小也会产生非等比缩放。以下偏差是旧采样单格宽高之比 `max/min - 1`，不是角色相似度或肉眼损坏程度。

chip_00 至 chip_32 旧采样宽高均有差异，范围 0.64%–23.73%；长岛、长门、巴尔的摩、胡德、俾斯麦、奇尔沙治最明显。它们已经用内置 imagegen 重绘，保留原有角色、配色及芯片插画主题。大青花鱼 chip_33 保留已确认的 7 格插画，只从已有图中裁出 1440×864 的逻辑画布，没有重新生成头像。

## 生产渲染规则

- PNG 画布必须是 `列数 × U`、`行数 × U`，每格同一个 U；缺失格透明。倒角或引脚的 alpha 外接矩形不再用于决定尺寸。
- 删除 alpha 自动裁边、图标二次裁边及分别按宽、高切格补偿。资源直接加载完整 PNG。
- 源区和绘制区都是同样大小的正方形；唯一缩放系数是 `step / U`。未来比例错误的图片也使用一个标量，不再以拉伸补偿。
- 用明确的旋转与镜像基向量，保证先翻转再旋转，与 `PatchworkBoard.Cells` 一致。已修复旧 Godot 旋转/负缩放组合在 90°、270°时造成的格内错位。
- 导出只裁画布和清除空缺格 alpha，没有对 RGB 像素做缩放、挤压或扭曲。PNG 文件名、逻辑形状、格数及存档标识不变。
